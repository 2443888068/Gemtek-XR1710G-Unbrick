③ 完整恢复流程

X 模式刷 bootloader：按住 RESET 上电 → 按 X → 出现 CCCCC → 发 1_stage1_preloader.bin
再断电重启 → 提示 Press x to load BL31 + U-Boot FIP 时按 x → 发 2_stage2_bl31_uboot.bin
把本页生成的 dsd_*.bin 传到 0x81800000
flash erase 0x400000 0x8000 → flash write 0x400000 0x8000 0x81800000
同样方式写 uenv：flash erase 0x200000 0x400 → flash write 0x200000 0x400 0x81800000
重启，进系统检查 MAC、WiFi 是否正常

这个工具做了什么

项目状态
DSD 文本段（MAC/序列号/WiFi）按你的输入写入
WiFi 校准段（0x5000 起）内置同型号模板，原样保留
尾部结构标记保留
加密段（0x1000，PKCS#7×3）留空 —— 见下方说明
bootloader（BL1/BL2/BL31/U-Boot）X 模式两阶段文件已含
关于 0x1000 加密段：原厂是三个 PKCS#7 encryptedData 容器 （PBES2+PBKDF2+AES-128-GCM），逐台 salt/IV 不同。它不是签名、不参与校验。 本工具把它留空（0xFF）。
若实测发现设备必须要它，可以改用整份原厂 DSD 当模板（见 DSD加密段说明.txt）。
校准是否通用？同一型号硬件设计相同，校准通常可通用；但若原厂按 MAC 做了绑定， 换机后可能不生效。第一次给别的机器用时，建议做一次实测：写入后开机看 WiFi 能否正常起、 发射功率是否合理（iw dev / iw phy）。
