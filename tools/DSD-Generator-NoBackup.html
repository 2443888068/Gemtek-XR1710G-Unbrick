③ 别人的机器上怎么走完整个恢复

断电，按住 RESET 上电 → 按 X → 终端出现 CCCCC
发 1_stage1_preloader.bin（126,972 B）→ 自动重启
再断电，按住 RESET 上电 → 提示 Press x to load BL31 + U-Boot FIP 时按 x
发 2_stage2_bl31_uboot.bin（507,904 B）→ 自动重启
此时 bootloader 已完好；再进 U-Boot，用 TFTP/串口把本页生成的 dsd_*.bin 传到 0x81800000
写 DSD：flash erase 0x400000 0x8000 → flash write 0x400000 0x8000 0x81800000
写 uenv：flash erase 0x200000 0x400 → flash write 0x200000 0x400 0x81800000
上电进系统 → 检查 MAC 和 WiFi 是否正常
做不到的事（必须知道）：
· WiFi 射频校准是每台机器出厂单独测出来烧进去的，没有原厂 DSD 就无法重建。 机器能开机、WiFi 也大概率能连，但发射功率/灵敏度可能不达标， 5G 甚至可能起不来。
· DSD 0x1000 段是三个 PKCS#7 encryptedData 加密容器 （PBES2 + PBKDF2 + AES-128-GCM，逐台 salt/IV 都不同）。 它不是签名，不参与校验；但没有口令就无法解开， 本页生成的 DSD 里该段为空。
· 这直接影响"能不能拿别的机器的 DSD 来用"：密文是逐台的， 但口令是否与设备绑定，只能实测（见「DSD加密段说明.txt」里 5 分钟的验证方法）。
· 最省事的办法：找一台同型号正常机器，把它的 DSD 整段当模板 （只改 MAC/序列号），这样 0x1000 和 0x5000 段都保留。
